- Public API added (exact signatures; `tdp_core/model/__init__.py` stays docstring-only, import from the modules):
  - `tdp_core.model.priority`
    - `priority_from_scores(scores: npt.ArrayLike) -> npt.NDArray[np.int64]`: `round(100 * lower / n)` with
      halves rounded up, computed exactly as `(200 * lower + n) // (2 * n)`, where `lower` = number of strictly
      lower scores. Empty input gives an empty int64 array, n = 1 gives `[100]`, ties share a priority, the
      lowest of n >= 2 gets 0 (all equal gives all 0), the top of n distinct gets `round(100 (n-1)/n)`
      (100 for n >= 200, 99 for n = 100). `ValueError` for NaN, infinity or input that is not 1-D.
  - `tdp_core.model.calibration`
    - Constants `LOW_PERCENTILE = 5.0`, `HIGH_PERCENTILE = 95.0`, `JSON_KEYS = ("x", "y", "y_low", "y_high")`.
    - `class IsotonicCalibrator`
      - `__init__(self, x, y, y_low, y_high: npt.ArrayLike) -> None`: `ValueError` unless 1-D, equal length >= 1,
        finite, x strictly increasing, the three curves in [0, 1], non-decreasing and `y_low <= y <= y_high`
        (tolerance 1e-9, then clipped so the stored curves obey the rules exactly).
      - read-only properties `x`, `y`, `y_low`, `y_high -> npt.NDArray[np.float64]` (arrays are write-protected copies).
      - `@classmethod fit(cls, scores: npt.ArrayLike, y: npt.ArrayLike, *, n_boot: int = 200, seed: int = 42) -> IsotonicCalibrator`:
        sklearn `IsotonicRegression(increasing=True, out_of_bounds="clip", y_min=0, y_max=1)`; x and y are its
        `X_thresholds_` / `y_thresholds_`. Bootstrap: `rng = np.random.default_rng(seed)`, each refit resamples n rows
        with replacement and is evaluated with `np.interp` on the main x grid; bands are the 5th and 95th percentiles,
        then `lo = clip(minimum(maximum.accumulate(lo), y))`, `hi = clip(maximum(maximum.accumulate(hi), y))`.
        `n_boot=0` gives bands equal to y. Bool labels accepted. `ValueError` for empty, mismatched, non-finite or 2-D
        input, labels outside [0, 1] or `n_boot < 0`. sklearn is imported lazily inside `fit`.
      - `predict(self, scores: npt.ArrayLike) -> tuple[NDArray[float64], NDArray[float64], NDArray[float64]]`
        (risk, low, high) via `np.interp`; out-of-range scores get the end values; empty in, three empty arrays out;
        `ValueError` for NaN, infinity or 2-D input.
      - `to_json(self) -> dict[str, list[float]]` (keys in `JSON_KEYS` order, Python floats, exact JSON round trip).
      - `@classmethod from_json(cls, d: Mapping[str, Sequence[float]]) -> IsotonicCalibrator` (extra keys ignored;
        `ValueError` for a non-mapping, a missing key or any constructor rule).
  - `tdp_core.model.ranker`
    - `DEFAULT_NTHREAD: Final = 4`
    - `class Ranker`
      - `__init__(self, booster: xgb.Booster) -> None`: `ValueError` unless `num_features() == 89` and
        `feature_names` is None or exactly `FEATURE_INPUT_COLUMNS`. Warns when a `best_iteration` attribute is below
        the last round (scoring always uses every round).
      - `@classmethod from_json(cls, path: Path, *, nthread: int = DEFAULT_NTHREAD) -> Ranker`: loads with
        `xgb.Booster(params={"nthread": nthread, "device": "cpu"}, model_file=str(path))`. `FileNotFoundError` if not a
        file, `ValueError` if empty, `nthread < 1` or unparsable (`XGBoostError` is a `ValueError`).
      - `score(self, X: pd.DataFrame) -> npt.NDArray[np.float64]`: columns must equal `FEATURE_INPUT_COLUMNS` exactly
        (order included, the error says how many are missing or extra, or that the order differs); values cast to
        float32, NaN means missing, index ignored, empty frame gives shape `(0,)`. Uses
        `booster.inplace_predict(arr, predict_type="margin", validate_features=False)` (lock free, thread safe), equal
        bit for bit to `booster.predict(xgb.DMatrix(X), output_margin=True)`.
      - `@property booster -> xgb.Booster`; `repr` is `Ranker(features=89, rounds=50)`.
  - `tdp_core.model.synthetic`
    - `SYNTHETIC_START: Final = datetime(2019, 1, 7, tzinfo=UTC)`, `SYNTHETIC_REPO_PREFIX: Final = "synthetic__repo"`
    - `synthetic_dataset(n_queries: int = 30, rows_per_query: int = 200, *, snapshots_per_repo: int = 5, seed: int = 42, settings: Settings = DEFAULT_SETTINGS) -> pd.DataFrame`:
      columns `INDEX_COLUMNS + FEATURE_INPUT_COLUMNS + LABEL_COLUMNS + ("qid",)`, sorted by qid then path, RangeIndex.
      Query q is snapshot `q % spr` of repo `synthetic__repo{q // spr:02d}`, `snapshot_time = SYNTHETIC_START +
      snapshot_idx * settings.snapshot_step_days` days (UTC, `datetime64[us, UTC]`), `qid == q`; paths
      `pkgNN/module_III.py` repeat across a repo's snapshots. Dtypes: repo/path `str`, snapshot_idx int16, features
      float32, labels int32, int32, float32, int8, bool, qid int32. `pct_` columns are the within-query
      `rank(pct=True, method="average")` of the stored float32 values; pain and grade follow the P2.6 rules with
      `settings.gamma` (grades computed from the stored float32 pain). Same seed, same frame. `ValueError` for any
      size below 1.

- Bundle rules as implemented:
  - `load_bundle`: missing or non-directory path gives `FileNotFoundError`. A missing required file, a feature schema
    that is not `{"extractor_version": EXTRACTOR_VERSION, "columns": FEATURE_INPUT_COLUMNS}` exactly (the message
    says version, missing/extra counts or order), metadata that is not an object with a valid string `version`, a
    bad calibrator payload, an empty or unparsable ranker, invalid UTF-8, bad JSON or YAML, or YAML that is not a
    mapping all give `BundleSchemaError` whose message starts with the file name. Other `OSError`s propagate.
    reasons and cost_model: bundle file, else package default, else `{}`; an empty YAML file gives `{}`.
  - `save_bundle`: validates the version, rejects a conflicting `metadata["version"]`, copies the metadata and fills
    the default keys (`created_at` = now UTC without microseconds, written as ISO with `Z` by `to_jsonable`; numpy
    scalars become numbers, tuples lists). Every payload is serialised before anything is written (a bad version,
    NaN or infinity, an array or any non-JSON value raises `ValueError` and leaves no directory). Trims a booster with
    a `best_iteration` attribute to `booster[:best_iteration + 1]`, then validates it with `Ranker` (bad shape gives
    `BundleSchemaError`). Writes ranker.json (`save_model`), calibrator.json, feature_schema.json (indent 2), the two
    YAML files (given mappings as `yaml.safe_dump(..., sort_keys=False, allow_unicode=True)`; None byte-copies the
    package default, comments kept, or removes a stale copy when there is no default) and metadata.json last
    (indent 2, sorted keys, `allow_nan=False`). An existing metadata.json is removed before writing, so a crashed
    save never looks complete. All text is UTF-8 with `\n` newlines. model_card.md is the caller's job.
  - `make_dev_bundle`: refuses (`FileExistsError`, nothing written) a path that is a file, a directory holding any
    file that is not a bundle file (for example `models/` with production.json), or a directory whose metadata.json
    is not a synthetic bundle's; rebuilding a dev bundle in place is allowed. Trains
    `XGBRanker(**DEV_RANKER_PARAMS, monotone_constraints=dict(DEV_MONOTONE_CONSTRAINTS), random_state=seed)` on
    `synthetic_dataset(30, 200, seed=seed)` grades with qid, fits the calibrator on in-sample margins against
    `has_latent_defect` (200 bootstraps), version `dev-%Y%m%dT%H%M%SZ` (or the `version` argument), metadata adds
    `synthetic: true`, `seed`, `queries`, `rows_per_query`, the full params and `metrics: {}`, then writes a model card
    (intended use, data, metrics, limitations) that says it must never be promoted. Same seed gives byte-identical
    ranker.json, calibrator.json and feature_schema.json.
- Deviations from the plan and why:
  1. `model/__init__.py` left docstring-only (section 15.4 overrides the Owns list).
  2. `BundleSchemaError` lives in bundle.py; `Ranker` and `IsotonicCalibrator` raise `ValueError` and the bundle
     functions re-raise as `BundleSchemaError` (no import cycles). Missing directory is `FileNotFoundError`, a missing
     file inside it is `BundleSchemaError`.
  3. `Ranker.score` enforces the exact column order and special-cases empty frames (XGBoost returns shape (0, 0)).
  4. `Ranker.from_json` caps threads at 4 (15.3) and forces `device="cpu"` so GPU-trained models score anywhere; the
     model is always loaded from its path (a zero-length in-memory buffer crashed the interpreter in the planner's
     prototype). Non-ASCII Windows paths load fine (tested).
  5. Early-stopped boosters are trimmed at save time: sklearn's `predict` uses `best_iteration + 1` rounds, but
     `inplace_predict` and SHAP use all of them.
  6. Calibration bands are clamped to bracket the risk and kept monotone, because `FileScore` and the UI assume
     `risk_low <= risk <= risk_high` and raw bootstrap percentiles do not guarantee it. `n_boot=0` is allowed.
  7. Priority rounding is half up in exact integer arithmetic (the plan's `round` is ambiguous at .5).
  8. Bundle versions are validated (safe folder names and database keys); metadata always holds the documented
     keys; NaN and infinity are rejected (Postgres JSONB and browsers reject them); a conflicting version raises.
  9. Optional YAML files are byte-copied from the package defaults and stale copies are removed; loading falls back
     bundle file, then package default, then `{}`, and logs the source at debug level.
  10. `synthetic_dataset` is public in its own module (`tdp_core.model.synthetic`) because later steps need the
      same frame in the dataset.parquet layout for their tests.
  11. The dev ranker uses parameters like P3.3's plus monotone constraints. Grades are still driven mainly by churn,
      prior bugs and dependents; smaller complexity, duplication, SATD, cycle and test effects let reasons cover
      several families and make the what-if direction hold for certain.
  12. `make_dev_bundle` takes an optional `version` keyword, writes a model card and refuses to overwrite a real
      bundle or write into a folder of unrelated files (the second guard is an addition to the plan).
  13. One test module per runtime module plus `tests/model/conftest.py` (15.4 allows a conftest in the step's folder).
  14. `Bundle` hides the large dicts from `repr`; `save_bundle` takes `Mapping` instead of `dict` (broader,
      compatible). `save_bundle` serialises everything before writing and removes an old metadata.json first.

- Known issues / limitations:
  - Dev metrics are in-sample on synthetic data and say nothing about real code; the dev bundle has `metrics: {}`.
  - The default dev version has one-second resolution; two dev bundles built in the same second share a version
    (pass `version=` when that matters).
  - YAML top-level keys are not checked to be strings (PyYAML turns `yes`/`no` keys into booleans).
  - A save that crashes after removing metadata.json leaves a directory that `load_bundle` rejects until it is
    saved again.
