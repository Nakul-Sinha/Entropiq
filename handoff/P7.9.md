# Handoff P7.9: CLI views for fix plans, what-if, advice and export
- Status: done

## What was built

Four plug-in command modules for the interactive Entropiq shell, each also a non-interactive Typer subcommand,
plus two private helpers. They use only the P7.1 plug-in API (no new hook was needed) and the shared theme.

| Shell command | Aliases | Group | CLI | What it does |
| --- | --- | --- | --- | --- |
| `/plan [--budget HOURS]` | | Plan | `tdp plan [PATH] [--budget H] [--format table\|md\|json]` | budgeted fix plan from `tdp_core.planning`: order, path with its reason on a dim second line, group, hour range, return on effort, cumulative benefit bar, totals |
| `/whatif <path> [--add-tests] [--split] [--dedupe] [--resolve-satd] [--break-cycle] [--all]` | `/what-if` | Explore | `tdp whatif FILE [PATH] <flags> [--format table\|json]` | before and after priority, band and risk plus the changed features; in the shell with no flags a checkbox picker |
| `/advise <path> [--refresh]` | `/advice` | Plan | `tdp advise FILE [PATH] [--refresh] [--format text\|json]` | grounded AI fix advice through `tdp_core.advisor` (spinner, cache, numbered steps with targets and effort, labelled as AI suggestions); without `ANTHROPIC_API_KEY` one panel explains how to enable it |
| `/export md\|json\|sarif [-o FILE] [--top N] [--min-band high\|critical]` | `/report` | Report | `tdp report [PATH] [--format md\|json\|sarif] [-o FILE] [--top N] [--min-band high\|critical]` | writes the analysis with the `tdp_core.report` writers and prints where it went |

File arguments (`/whatif`, `/advise`, `tdp whatif`, `tdp advise`) accept the exact path, `.\pkg\mod.py`, any case,
an OS path inside a local repository, a unique ending (`mod.py`) or a rank (`3` or `#3`, the priority order of the
ranking views).

## Public API added (exact signatures, module paths)

`tdp_cli.commands._file_arg` (helper, not a plug-in)
- `FileArgument` (Typer `Annotated[str, typer.Argument(...)]`), `UNKNOWN_HINT`, `MAX_LISTED = 5`, `RANK_PATTERN = re.compile(r"^#?(\d+)$")`.
- `normalize_path(raw: str) -> str` (backslashes to slashes, leading `./` removed).
- `resolve_file(loaded: LoadedAnalysis, raw: str) -> FileScore`. Order: exact normalized path, rank (out of range: `UsageError("no file has rank N; ranks go from 1 to M")`), unique case-insensitive match, OS path inside a local repo, unique suffix, else `UsageError` with close matches as the hint. An ambiguous suffix lists up to 5 matches.

## Output formats

- `entropiq.plan.v1`: `{"schema", "repo", "sha", "model_version", "budget_hours", "min_priority", "total_hours", "total_benefit", "candidate_files", "candidate_benefit", "steps": [{"order", "path", "group", "benefit", "roi", "cost_hours", "cost_low", "cost_high", "reason"}]}`. `tdp plan --format md` is `plan_to_markdown(plan)`.
- `entropiq.whatif.v1`: `{"schema", "repo", "sha", "path", "actions", "model_version", **WhatIfResult.to_json()}` (`before`, `after`, `changed_features`, ...).
- `entropiq.advice.v1`: `{"schema", "repo", "sha", "path", "blob_sha", "model", "cached", "created_at" (ISO, Z), "advice": Advice.model_dump(mode="json")}`.
- Reports: md = `to_markdown(result, top) + "\n" + plan_to_markdown(result.plan)`; json = `to_json(result)` (`tdp-report`); sarif = `json.dumps(to_sarif(result, min_band), indent=2) + "\n"`. UTF-8, `\n` line ends.
- Default export name: `<slug with [^A-Za-z0-9._-] replaced by ->-<sha7>.<md|json|sarif>` in the current folder (`psf__requests-3c7baaa.sarif`; local repositories give `pallets__click-fbba2a2c-2247b35.json`); `-o DIR` or a value ending in `/` or `\` puts the default name inside that folder; `-o -` prints the report (stdout in the CLI).
- Advice cache: `<Entropiq home>/advice/<Advisor.cache_key(blob_sha, model)>.json` = `{"schema": 1, "model", "prompt_version", "path", "blob_sha", "created_at", "advice"}`, written atomically; an unreadable entry is ignored and replaced on the next request.

## Deviations from the plan and why

1. D1. The interrupted attempt's design and names were kept; this attempt fixed lint and mypy and added the missing commands and tests. The plan table puts each reason on a second line under its path and lets only that cell wrap, so the order, hours, return and bar columns stay whole at 80 columns (a separate Reason column was squeezed to nothing there and paths were cut).
2. D2. File arguments also accept a rank (`3` or `#3`), the numbering of the ranking views; an exact path that looks like a number still wins.
3. D3. `-o` is mapped inside `/export` because `tdp_cli.args.parse_args` only knows long options and `args.py` is shared.
4. D4. Without `-o`, `tdp report` writes the default file name in the current folder, the same as `/export`; `-o -` means stdout, and the "Wrote ..." line goes to stderr so stdout stays clean.
5. D5. The `/export` format is required (as in the orchestrator usage); `markdown` is accepted. Extra options: `--top` (Markdown rows, default the `top` setting, 0 lists all) and `--min-band` (SARIF). `/report` is a shell alias, `tdp report` the CLI name.
6. D6. The advice cache key is the platform's `Advisor.cache_key(blob_sha, model)`. The cache is read before the key check, so saved advice shows without a key; `--refresh` bypasses it.
7. D7. `tdp advise` with no key and no saved advice prints the panel on stderr and exits 1; the shell only shows the panel.
8. D8. No dependency change: `anthropic` comes into the workspace through the worker's advisor extra. A `tdp-cli` install without `tdp-core[advisor]` gets "AI advice is unavailable" plus an install hint.
9. D9. Groups: Plan (`plan`, `advise`), Explore (`whatif`), Report (`export`). `/whatif` keeps `--all` and the `what-if` alias; `/advise` has the `advice` alias.
10. `tdp whatif` and `tdp advise` take the file first, then the repository (`tdp whatif FILE [PATH]`), because the repository defaults to `.`.

## Known issues / limitations

1. No real Anthropic call was made (no key on the build machine); every test uses `FakeLLMClient` through `client_factory`, and the real client constructor is stubbed in its one test.
2. `tdp-cli` does not depend on the `advisor` extra; a standalone install without `tdp-core[advisor]` shows the install hint instead of advice.
3. `_file_arg.resolve_file` duplicates the finder of the parallel `/files` step (P7.8); once both are on main the two can share one helper.
4. The what-if view says "no change" when the demo model is saturated (risk 100%), which is a property of the demo bundle.
5. A cached answer is keyed by file content and model, not by the analysis; advice for an unchanged file is reused across commits, which is intended.
