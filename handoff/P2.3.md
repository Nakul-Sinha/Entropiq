- Definitions (module docstrings):
  - Test files are exactly `test_paths`; the graph's `is_test` node attribute is never read.
  - `has_test_file` = 1 when some test file's basename is `test_<s>.py` or `<s>_test.py` for a stem `s` of the
    file, anywhere in the repository; exact and case sensitive. Stems: `__init__` has none (always 0); a dunder
    stem (`__main__`, `__version__`) is only itself; any other stem with leading underscores also tries the stem
    without them (`_compat` tries `_compat` and `compat`).
  - Package key `top_level_package(p)`: `parts[0] + "/" + parts[1]` when `parts[0]` is in
    `tdp_core.graph.imports.SOURCE_ROOTS` (`src`, `lib`) and there is a second part, else `parts[0]`. Root files and
    files directly under a source root are their own package (`setup.py`, `src/mod.py`). The key only groups files.
  - `pkg_test_ratio(p) = tested_sloc[k] / max(source_sloc[k], 1)` with `k = top_level_package(p)`.
    `source_sloc[k]` sums the SLOC of every non-test key of `syntax_by_path` in `k` (not only the requested rows).
    `tested_sloc[k]` sums, over test files that are graph nodes, the test's SLOC once for each package that holds
    at least one non-test file the test imports (successors). Test to test edges and non-test importers never
    count. The value is 0 or more and can exceed 1.
  - Tolerated (none raises): a row or test missing from `syntax_by_path` is 0 SLOC; a test path that is not a graph
    node contributes nothing; test files may be rows. Cost O(files + edges).
  - SATD comments are `FileSyntax.comments`: one per `#` comment line, text without the first `#`, stripped.
    Docstrings and other strings are not comments.
  - Without a classifier every candidate counts. With one, `predict_proba` is called exactly once per file with the
    candidate texts (never with an empty list) and candidates with probability `>= threshold` count.
  - `satd_density = 1000 * count / max(sloc, 1)` (comments per 1,000 SLOC). `satd_age_days` = max over counted
    comments of `line_ages_days.get(line)` that are finite, clipped at 0; 0.0 when `line_ages_days is None` or no
    counted line has a known finite age. Ages of other lines and of rejected candidates are ignored.
- Deviations from the plan and why:
  1. `has_test_file` also tries the stem without leading underscores for private modules (not dunders), a superset
     of the plan's rule. The exact rule misses the common convention where `_client.py` is tested by
     `test_client.py`. Measured on all 23 mirrors at HEAD over parsed non-test files (`skip_reason` applied):
     881 to 925 of 3,816 files; httpx 2 to 13 of 23, attrs 6 to 13 of 24, rich 45 to 52 of 125, loguru 0 to 4 of
     20, mitmproxy 184 to 188.
  2. The package key uses `SOURCE_ROOTS` (`src` and `lib`) from `tdp_core.graph.imports` instead of `src` alone,
     so the grouping matches how the import graph names modules. No difference on the 23 mirrors.
  3. Clarifications the plan leaves open: root files and files directly under a source root are their own
     package; the set of test files is exactly `test_paths`; only test to non-test edges count, and a test counts
     once per package; the denominator is every non-test file in `syntax_by_path`, with `max(SLOC, 1)`; missing
     syntax counts as 0.
  4. The `SatdClassifier` return type is `npt.NDArray[np.floating[Any]]` (the plan writes `np.ndarray`, which
     `mypy --strict` rejects without type arguments). Implementations returning float64, float32 or
     `NDArray[Any]` all conform. The merged `JsonSatdClassifier` returns `NDArray[np.float64]`;
     `test_shipped_classifier_filters_candidates` assigns `load_default_classifier()` to a `SatdClassifier`
     variable, so mypy checks the pairing, and runs it through `satd_features`.
  5. Validation: `ValueError` for a threshold outside 0..1 or NaN (checked first, even without candidates), and for
     classifier output whose shape is not `(n_candidates,)` or that contains NaN. The classifier is skipped when a
     file has no candidates. Negative ages clip to 0 and non-finite ages are ignored.
  6. `test_features.__test__ = False`: pytest collects any module-level callable named `test_*` in a test module,
     imported ones included, so `from tdp_core.features.tests_signals import test_features` in a test file would
     otherwise fail with "fixture 'paths' not found". Any test module may import it by name.
  7. Extra public names: `TEST_SIGNAL_COLUMNS`, `top_level_package`, `SATD_COLUMNS`, `SATD_PATTERN`.
  8. Branch name `step/P2.3-test-signals-and-satd-features` (set by the orchestrator) instead of
     `step/P2.3-tests-satd`.
  9. Kept as planned: the SATD regex, exactly. Over all parsed files of 11 repos: 348 candidates (xxx 125, todo 123,
     temporary 29, hack 19, workaround 18, fixme 18, work around 10, ugly 6). Plural and adjective variants would
     add only 12 ("hacky" 3, "temporarily" 9, mostly not debt); plurals never occurred.
  10. Kept as planned: per-line counting. A multi-line debt comment can count more than once, and the classifier
      sees one line at a time.

- Known issues / limitations:
  - TODOs in docstrings are not counted (they are strings, not comments).
  - Basename matches are repo-wide, so common names such as `utils.py` match unrelated tests named `test_utils.py`.
  - Directory-based test layouts (`tests/pkg/mod/test_basic.py` for `pkg/mod.py`) are not matched;
    `test_importers` covers import-based testing.
  - `pkg_test_ratio` is package level and static-import only, and thin facade packages get extreme values
    (pytest `src/pytest` 263.85, attrs `src/attrs` 64.45: tests import the facade, which holds little SLOC).
  - Without a classifier, "temporary", "ugly" and "XXX" catch non-debt comments.
- Notes for dependent steps (by ID):
  - P2.4 (merged first): its `JsonSatdClassifier` already satisfies the Protocol. The contract it relies on:
    `predict_proba(texts: Sequence[str])` returns a 1-D float array (float64 recommended) of
    `len(texts)` values in 0..1, in input order. Each text is one `CommentInfo.text` line (no leading `#`,
    stripped), and only regex candidates are sent; `satd_features` never calls it with an empty list. The default
    threshold is 0.5 and the test is `>=`. `SATD_PATTERN` can select the hand-labelled fallback set. The classifier
    matters most for "temporary", which is mostly non-debt ("Create a temporary file"). `satd.py` is owned here;
    import the Protocol from `tdp_core.features.satd`.
  - P2.7: call `test_features(rows, test_paths, syntax, import_graph)` with `syntax` including the test files and
    the same graph that `graph_features` gets; join on the `path` index. `has_test_file` is binary (no `pct_`
    copy); `pkg_test_ratio` and the three Q columns get `pct_` copies. Cast to float32. SATD:
    `cands = satd_candidates(syntax[p].comments)`; run blame only for files with candidates, on the lines
    `{c.line for c in cands}`; ages are `(T - author_time) / 86400` per line; then call
    `satd_features(syntax[p], satd_model, ages)`. A file without candidates needs no blame: pass `None` and the
    result is zeros.
